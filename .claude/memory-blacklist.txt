# Memory sharing blacklist.
# Lists paths whose changes are NOT propagated across collaborators by default.
# Used by:
#   - scripts/apply_memory_filter.sh (post-merge hook): reverts these paths to
#     the local version after a merge unless MIND_MELD=1 is set.
#   - scripts/mind_meld.sh: drives LLM semantic merge on [soft] paths when
#     the user invokes `git mind-meld`.
#
# Two tiers:
#   [soft]  — blacklisted by default; MIND_MELD=1 allows them to merge normally
#   [hard]  — always filtered, regardless of MIND_MELD (per-machine state that
#             has no shared meaning)
#
# Paths are git-relative. Trailing / indicates a directory (all contents).
# Lines starting with # are comments. Blank lines ignored.
#
# Customize this file for your project: add/remove memory paths to match
# which Serena memories your agent set uses.
