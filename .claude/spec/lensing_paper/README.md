# Chang-Refsdal relative-binning paper, v5

This revision changes the fixed-topology example to a pair of sources outside the same fold at
`eta_s=-0.040` and `eta_s=-0.010`.  The complete amplification ratio now exhibits clearly shifted
interference minima, while the separated amplitude ratios remain smooth.  With candidate-fiducial
delay phases retained exactly, the adaptive interpolation test reaches the stated error threshold
with 11 separated-ratio nodes, versus 135 of 141 frequencies for direct interpolation of the total ratio.
